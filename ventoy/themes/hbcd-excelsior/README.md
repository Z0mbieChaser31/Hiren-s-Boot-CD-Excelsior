# Hiren's Boot CD Excelsior — Boot Theme

This directory contains the custom GRUB2 boot theme for Hiren's Boot CD Excelsior.

## Files

| File | Description |
|------|-------------|
| `theme.txt` | Main GRUB2 theme definition |
| `background.png` | Boot menu background image (generated by setup.py) |
| `DejaVuSans.pf2` | Main font (copy from GRUB font package) |
| `DejaVuSans-Bold.pf2` | Bold font for titles |
| `icons/` | Category and OS icons (32×32 PNG) |
| `select_*.png` | Selection highlight images |
| `scrollbar_thumb.png` | Scrollbar thumb image |

## Customizing the Theme

You can edit `theme.txt` to change:
- Colors (hex `#RRGGBB` format)
- Font sizes
- Layout positions (percentages)
- Menu item height and spacing

After editing, copy the theme folder to `/ventoy/themes/hbcd-excelsior/` on your USB drive.

## Getting the Fonts

GRUB2 `.pf2` font files can be generated with:

```bash
# Linux (grub-mkfont must be installed)
grub-mkfont --output=DejaVuSans.pf2 --size=16 /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf
grub-mkfont --output=DejaVuSans-Bold.pf2 --size=16 /usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf
```

On Windows, Ventoy ships with pre-built fonts you can copy from its installation directory.
